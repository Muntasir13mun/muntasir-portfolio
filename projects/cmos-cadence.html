PROJECT CASE STUDY

Design and Implementation of Complementary CMOS Logic Using Cadence EDA

A VLSI design-lab project using Cadence Virtuoso to design, simulate, lay out, and verify an AOI CMOS logic gate using a 45 nm process.

VLSICadence Virtuoso45 nm CMOSAOI logicDRC / LVS
Back to selected projects

Design objective

Implement the Boolean function F = NOT((A AND B) OR (C AND D)) while balancing functional correctness and physical layout area.

Design flow

  • Schematic capture and transistor sizing
  • Pre-layout transient simulation
  • Stick-diagram and physical layout generation
  • Euler-path ordering A–B–D–C to support diffusion sharing
  • Design Rule Check (DRC) and Layout Versus Schematic (LVS)

Verification reported

The report states that the design produced the intended AOI logic behaviour and that the layout passed DRC and LVS consistency checks.

Skills demonstrated

  • Complementary CMOS logic design
  • Cadence EDA workflow
  • Transient simulation and layout design
  • Physical verification and area-aware transistor ordering

Project context

Academic VLSI group project. Muntasir Mahmud is listed as the first author of the submitted report.
