PROJECT CASE STUDY

Design and Implementation of a Dual-Sensor Fire Detection System

An academic sensor-and-controller prototype combining smoke/gas detection and infrared flame sensing to trigger local visual and audible alerts.

Arduino UnoMQ-2 gas/smoke sensorIR flame sensorBuzzerLED alert
Back to selected projects

Objective

Detect early indicators of a possible fire using two sensing methods and provide an immediate alert when programmed sensor thresholds are crossed.

System components

  • MQ-2 gas/smoke sensor module
  • Infrared flame sensor
  • Arduino Uno microcontroller
  • Buzzer and LED indicators
  • Breadboard prototype and sensor calibration

Methodology

The report describes component selection, circuit design and simulation, hardware implementation, controlled smoke/flame testing, and adjustment of thresholds to reduce false triggers.

Reported observations

The report describes sensor readings being monitored through the Arduino serial monitor, with audio-visual alerts activated when readings crossed predefined thresholds. Reported test distances are experimental observations, not certified safety specifications.

Skills demonstrated

  • Sensor integration and threshold logic
  • Microcontroller-based monitoring
  • Basic circuit testing and calibration
  • Prototype documentation
Academic group project. This prototype is for learning and demonstration; it should not be treated as a certified fire-alarm system.
