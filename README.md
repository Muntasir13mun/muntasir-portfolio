## Publish with GitHub Pages
This repository is public so the portfolio can be viewed by recruiters. The deployment workflow file was removed from this public repository to avoid publishing workflow source here.

For branch-based Pages publishing, open **Settings → Pages** and select:
- **Source:** Deploy from a branch
- **Branch:** `main`
- **Folder:** `/(root)`
- Click **Save**

GitHub Pages will serve `index.html` and the project pages directly from the `main` branch.
